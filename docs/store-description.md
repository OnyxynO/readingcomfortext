## Résumé court (Summary, ≤250 caractères)

Confort de lecture pour tout le web : polices adaptées, espacement réglable, fond crème et lecture audio. Pensé pour les personnes dyslexiques ou malvoyantes. Chaque option indique si elle est scientifiquement validée. Aucune donnée collectée.

## Description longue

ReadingComfortExt applique des options de confort de lecture sur n'importe quel site web, pensées pour les personnes dyslexiques, malvoyantes ou sujettes à la fatigue visuelle.

**Fonctionnalités**

- Polices adaptées : Lexend, Atkinson Hyperlegible, OpenDyslexic
- Espacement réglable : espacement des lettres, hauteur de ligne, largeur de colonne
- Fond crème et texte non justifié
- Guide visuel : lignes colorées pour faciliter le suivi de lecture
- Lecture audio (TTS) via la synthèse vocale native du navigateur

**Transparence scientifique**

Chaque option est badgée Sci ✓ (soutenue par la recherche) ou Pref (préférence subjective, sans preuve d'efficacité établie) — pour que vous sachiez ce qui repose sur des données et ce qui relève du confort personnel.

**Vie privée**

Aucune donnée personnelle n'est collectée. Vos préférences restent stockées localement dans votre navigateur (synchronisées entre vos appareils si vous êtes connecté à votre compte Firefox). OpenDyslexic est embarquée directement dans l'extension ; Lexend et Atkinson Hyperlegible ne sont chargées depuis Google Fonts que si vous les sélectionnez.
